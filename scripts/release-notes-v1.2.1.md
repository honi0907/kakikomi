## Kakikomi v1.2.1

### 新機能
- ネタ切替時の短いクロスフェード（設定で ON/OFF、操作画面・クリーン出力の両方）
- 操作バーを映像の上に配置するオプション（ボタン → シークバー → 映像）
- ペン太さ 3 プリセット（既定 8 / 16 / 24、設定で変更可）
- 変速再生でも音声を出すオプション（設定、既定 OFF）
- コンパネ起動時フルスクリーン・即時フルスクリーン
- 設定画面を TreeView ナビに再構成

### 修正
- 2回目以降の同一ネタ選択で映像が黒のままになる問題を再修正
- 2倍速再生時の黒ちらつきを改善
- クロスフェード時に黒が挟まる問題を改善

### 変更
- 起動時の編集モードを OFF に（3連打で ON）
- DEMO ウォーターマークを既定 OFF に
- 編集モード OFF 時はネタ一覧の fps 表示を非表示

### 配布
- Setup インストーラー（オンライン更新用）
- ポータブル ZIP

インストール後、設定の「オンライン更新を確認」から更新できます。
