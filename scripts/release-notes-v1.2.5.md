## Kakikomi v1.2.5

### 新機能
- 遠隔操作 Web UI に「保存」タブを追加
  - save フォルダ内の PNG 一覧表示（最大 200 件）
  - タップで画像プレビュー（`GET /api/saves` / `/api/saves/ファイル名.png`）

### 修正
- 遠隔接続中に書き込み後の再生再開で映像がもたつく問題を改善
  - 遠隔プレビューの JPEG 化をバックグラウンドへ移動
  - 再生再開直後はプレビューを一時休止（本番映像を優先）

### 配布
- Setup インストーラー（オンライン更新用）
- ポータブル ZIP

インストール後、設定の「オンライン更新を確認」から更新できます。
